## What is Interactivity?
**Interactivity** adds high-performance [Jolt Physics](https://github.com/jrouwe/JoltPhysics) for Minecraft.

Interactivity is created for [InteractiveMC](https://modrinth.com/mod/interactivemc) project, but it can also be used independently.

## Current features
- Comprehensive API for creating your own physical bodies and logic
- Collisions with terrain
- Constraints system
- `/interactivity` command

## Planned features
The main goals for future development include:
- More powerful API
- Client-side predictions
- Custom Sable physics pipeline
- (Immersive) Portals compatibility
